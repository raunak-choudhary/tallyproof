# ADR-0005: Replay mode for the public demo

- Status: Proposed (MC-01)
- Date: 2026-10-26
- Zone: Locked requirement (REQ-OPS-02), design is ours

## Context

Recruiters will open a link once, possibly weeks later. Free-tier backends sleep, expire, or rate-limit. The brief forbids the public demo from depending on any always-on free-tier service, and requires that nothing is faked.

## Decision

The public site is a static Next.js export (`output: 'export'`) plus a **replay bundle** generated by `make replay` from a real pipeline run:

```
replay/
  manifest.json            bundle version, git SHA, seed, created_at, SHA-256 of every file
  log-key.json             public key, origin, key_id
  events.jsonl             canonical events with leaf indexes
  checkpoints.jsonl        every signed checkpoint
  proofs/                  inclusion proofs per cited event (or computed in browser from leaf hashes)
  answers/                 precomputed answers for a fixed question list, with claims and citations
  evals/                   eval runs and per-question results
  stream.jsonl             timing data to replay the live stream view
```

In the browser:
- The stream view replays `stream.jsonl` on a timer (labeled "Replay of a recorded run").
- Every Verify recomputes hashes and checks the Ed25519 signature locally. Nothing is precomputed as "verified".
- The tamper demo edits the in-memory copy and re-verifies.
- The analyst page offers the fixed question list and says clearly that new questions need the local stack.

## Reasons

- No backend, so nothing sleeps and the attack surface is static files.
- Proofs are real: produced by the real pipeline, checked by independent client code.
- Same verification library as live mode, so the demo exercises production code paths.

## Constraints

- Next.js static export needs `generateStaticParams()` for dynamic routes and `dynamicParams = false`. Per-entity pages exist only for entities in the bundle; others route to a "not in this replay" page.
- No rewrites, headers, middleware, or server actions in the exported build.

## Hosting

Vercel static hosting (MC-06). GitHub Pages build kept as a fallback target, since a static export works on both.
