# Core library

`tallyproof_core` is the dependency-free heart of the project: canonical event bytes, leaf hashing, the RFC 9162 Merkle log and its proofs, signed checkpoints, money, IDs, the journal, and the reconciliation rules. The web verifier reimplements the proof checks in TypeScript, and shared test vectors keep the two in step.
